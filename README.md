# 헷갈리는 선지는 정답과 닮았을까?

2026-10-21 국어 모의고사 10문항의 선지 50개를 3차원 벡터로 놓고, VPython(GlowScript) 시뮬레이션과 Streamlit 발표 자료로 보여 준다.

## 실행

```sh
uv sync
uv run streamlit run main.py
```

이 폴더 하나로 완결된다. Python 3.13(`.python-version`), 의존성은 `pyproject.toml`과 `uv.lock`이 정한다.

## 구조

| 파일 | 역할 |
|---|---|
| `main.py` | 발표: ⓪ 문제 풀이·배경 ① 탐구 질문 ② 시뮬레이션 ③ 원리 ④ 결과 분석 ⑤ 결론과 한계 ⑥ 퀴즈 |
| `presentation.py` | 문제 전문·선지별 통계 자료와 원리 적용 퀴즈 |
| `analysis.py` | 벡터 계산, 코사인 유사도, 난도 지수 D, 축 독립성, 축별 흔들림 통계 |
| `sim.py` | 선지 벡터를 그리는 VPython 코드를 만든다(glowscript.org에 그대로 붙여 넣어도 돈다) |
| `glowscript_view.py` | VPython 코드를 브라우저 안에서 컴파일·실행하는 iframe HTML |
| `data/exam.json` | 지문·발문·선지, 정답·내 답, 축·근거 지지도·단어 효과 정의와 선지별 단어 주석 |
| `tests/` | 문제 자료 연결과 Streamlit 화면 구성 회귀 테스트 |

## 테스트

```sh
uv run python -m unittest discover -s tests -v
```

## 벡터

- 축: x 사실 · y 관계 · z 개념 — 선지를 지문과 대조하는 세 기준. 0은 '지문에 근거 없음', +는 지문이 받침, −는 어긋남.
- 벡터 = 근거 지지도(직접 0.9 · 결합 0.6 · 해석 0.3) + 선지 속 단어 효과의 합, 축마다 −1~1로 자른다.
- 단어 효과는 세기별 단계다: 반의 −1.50 · 치환 −1.10 · 층위 −0.70 · 반사실 −0.40 · 부정 −0.30 · 부분부정·조건 −0.20 · 이중부정 −0.15 · 추측 −0.10.
- 난도 지수 D = Σ max(0, (cos − τ) / (1 − τ)), τ = 0.70. 지수는 소수점 둘째 자리까지 쓴다.

## 동작

- 컴파일과 렌더는 보는 사람의 브라우저가 glowscript.org 라이브러리로 맡는다. 인터넷 연결이 필요하다.
- 첫 탭에서 실제 지문·보기·발문·선지를 읽고 10문항을 직접 풀어 채점할 수 있다.
- 문제 뒤에서 탐구 배경, 사실·관계·개념 세 축, 핵심 용어 정의를 먼저 익힐 수 있다.
- 접힌 예시 데이터셋에서 선지 원문·벡터·정답·내 답을 함께 확인할 수 있다.
- 시뮬레이션 화면 아래 콘솔에 선지 좌표, 정답과의 코사인, 켠 선지 n개의 코사인 표, 가장 헷갈렸을 선지, 난도 지수가 나온다.
- 결과 분석에서 문항을 고르면 실제 지문·보기·발문·선지 전문과 선지별 코사인 통계를 나란히 볼 수 있다.
- 퀴즈는 개별 문항의 부속 정보 대신 코사인 유사도·난도 지수·벡터 축의 원리를 묻는다.
